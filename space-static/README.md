# naam-match demo

Transparent Hindi/English name matching for Indian land and loan records. Type a name from a land record (Devanagari) and one from a loan file (English) and see the verdict, the score and every step the matcher took. Runs entirely in the browser; nothing is sent anywhere.

Code, tests and benchmark: https://github.com/ayushwho18/naam-match (MIT). All examples are synthetic.
